La universidad necesita digitalizar el control de un parqueadero pequeño de 30 cupos que atienda a tres tipos de usuarios: estudiantes, docentes y visitantes.
Cada tipo de usuario paga tarifas distintas y tiene reglas distintas de acceso.
El programa debe simular el registro de entradas de vehículos durante un día, calcular cobros, aplicar descuentos y llevar estadisticas.
